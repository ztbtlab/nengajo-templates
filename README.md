# 年賀状サイトのテンプレート（2027・未年）

スマホで開いて画面を下へ送ると、絵が動き、家族の写真が1枚ずつ出てくる年賀状のページです。
見た目の違う5種類があり、どれも HTML ファイル1つと画像だけでできています。

見本: https://nengajo.ztbtlab.com/

写真と「佐藤家」は、見本用に作った架空の家族です。絵と写真は、Codex の画像生成で作りました。

## 5種類のテンプレート

| フォルダ | 名前 | 中身 |
|---|---|---|
| `01-hitsuji-sanpo/` | ひつじのおさんぽ（絵本風） | ひつじが草原を歩き、毛糸玉に届くたびに写真が切り替わる |
| `02-wa-emaki/` | 新春絵巻（和風） | 和紙の絵巻が流れる。文字は縦書き、写真は掛け軸に |
| `03-ichinen-album/` | わが家の一年アルバム（スクラップブック風） | クラフト紙の台紙にポラロイド風の写真。タップで大きく見られる |
| `04-omikuji/` | 新春おみくじ（参加型） | 開いた人がおみくじを引くと、運勢と一緒にメッセージが出る |
| `05-hatsuhinode/` | 初日の出（映像風） | 夜が明けて日が昇る。言葉は字幕のように1行ずつ |

`index.html` は5種類を並べた一覧ページです。

## 自分の年賀状にする

各フォルダの `index.html` の先頭に、差し替える部分がまとまっています。

- `const CONFIG = { … }`: 挨拶文、宛名の既定値、写真とひとこと、差出人の名前
- その下の `:root { --paper: …; --accent: …; }`: 色

写真は `shared/photos/` に置いた6枚を使っています。自分の写真に差し替えるときは、`CONFIG.photos` の `src` を書き換えてください。

## 相手ごとに宛名を変える

アドレスの後ろに `?to=` と `?msg=` を付けると、宛名とメッセージが替わります。

```
https://example.com/01-hitsuji-sanpo/?to=田中さん&msg=今年もよろしく
```

ページの側では、受け取った文字を `textContent` で入れています（HTML としては入れません）。

## 公開する

フォルダごと、Cloudflare Pages などの静的なホスティングに置けば動きます。組み立ての工程はありません。外から読み込むのは Google Fonts だけです。

各ページには `noindex` を入れてあります。検索に出にくくするだけで、アドレスを知っている人は開けます。家族の写真を載せるときは、送る相手と公開する期間を決めておいてください。
